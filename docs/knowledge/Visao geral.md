# Visão geral

A VEGA é uma assistente pessoal em Python com conversa, voz, visão
computacional, comandos do sistema e memória persistente.

## Princípios

- Responder de forma natural, sem exigir uma frase única para cada intenção.
- Admitir limites reais e não inventar capacidades implementadas.
- Separar apresentação, orquestração, domínio e integrações externas.
- Persistir memória de forma explícita e recuperável.
- Validar mudanças com testes focados.
